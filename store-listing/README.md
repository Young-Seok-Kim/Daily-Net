# DailyNet 스토어 검색 개선

작성일: 2026-09-28

## 적용 상태

- 한국어 스토어 문안 작성 완료. Play Console에는 아직 저장하거나 제출하지 않음.
- hosting의 검색 메타데이터, canonical, SoftwareApplication 구조화 데이터, robots.txt, sitemap.xml 수정 완료. 온라인 배포는 아직 하지 않음.
- 연결 가능한 브라우저가 없어 콘솔 통계, 현재 한국어 등록 문안, 운영 서버 설정은 확인하지 못함.
- 공개 페이지 조회 결과는 영어 번역 및 검색 도구 수집본일 수 있어 현재 한국어 원문과 차이가 있을 수 있음.

## Play Console 입력

대상 패키지: com.youngs.dailynet

기본 스토어 등록정보의 한국어 항목에 아래 파일 내용을 입력:

- 앱 이름: ko-KR/title.txt
- 간단한 설명: ko-KR/short-description.txt
- 자세한 설명: ko-KR/full-description.txt

앱 이름 30자, 간단한 설명 80자, 자세한 설명 4,000자 제한을 검증한다.
카테고리는 공개 페이지의 건강/운동(Health & Fitness)을 유지한다.
태그는 콘솔의 실제 선택지 중 식단·영양·체중 관리 기능과 일치하는 항목만 선택한다. 검색량 검증 없이 특정 태그의 효과를 단정하지 않는다.
웹사이트 항목은 https://dailynet.web.app/ 가 정상 서비스되는지 확인한 뒤 등록한다.

키워드 방향: 식단 기록, 칼로리 계산을 중심으로 음식 사진, 탄단지, 다이어트 식단, 체중 기록을 기능 설명에 자연스럽게 포함했다. 검색량이나 순위 상승을 검증한 키워드 목록은 아니다.

스크린샷은 실제 출시 앱과 일치하는 화면을 사용하고 앞쪽에 식단 입력, 칼로리·탄단지 리포트, 월 정산 순서로 배치하는 안을 권장한다. 새로운 이미지 파일은 이번 작업에 포함하지 않았다.

## 배포 및 측정

홈페이지 변경은 웹 검색을 위한 것으로, Play Console 등록정보 수정과 별개다. Hosting만 배포하고 운영 함수나 규칙은 함께 배포하지 않는다.
배포 후 홈페이지, /robots.txt, /sitemap.xml 응답과 모바일 표시를 확인한다.
Search Console의 해당 사이트 소유권이 있으면 sitemap.xml을 제출한다. 사이트맵 제출과 구조화 데이터는 검색 노출이나 리치 결과를 보장하지 않는다.

콘솔에서 변경 직전의 완료된 28일을 기준으로 Google Play 검색 유입의 스토어 방문자, 설치 획득, 전환율, 제공되는 검색어별 실적을 보관한다.
변경 후 같은 길이의 완료된 기간과 비교하고 국가·언어·유입 경로를 맞춘다. 방문자가 적으면 발견 가능성을, 방문은 있는데 설치가 적으면 설명·스크린샷·제품 적합성을 살펴본다. 표본이 적을 때 변화율만으로 효과를 단정하지 않는다.

## 확인한 자료

- 공개 등록정보: https://play.google.com/store/apps/details?id=com.youngs.dailynet
- 등록정보 필드와 제한: https://support.google.com/googleplay/android-developer/answer/9859152
- 메타데이터 정책: https://support.google.com/googleplay/android-developer/answer/9898842

로컬 코드의 FREE_FOR_ALL=true와 공개 설명의 무료 하루 1회 안내가 달라 운영 상태 확인이 필요하다. 초안은 무료 횟수나 유료 혜택을 단정하지 않는다. 공개 설명의 이용 범위는 배포된 서버 설정과 대조한 후 확정한다.
